Memorial Baja builds a single-seat off-road Baja SAE racing vehicle to compete in the Baja SAE Ohio competition.

The vehicle has an ESP32-S3 microcontroller which connects to an onboard tablet via Bluetooth Low Energy (BLE) to display real-time sensor data, such as drive shaft RPM, temperature, and fuel level, to display to the driver. As a firmware developer, my contributions include:

  • Developed C firmware on an ESP32-S3 microcontroller to measure drive shaft RPM from hall effect sensor data and establish communication to the digital display via BLE.
  • Sourced a magnet with desired specifications for use with the hall effect sensor to calculate RPM.
  • Tested the hall effect sensor using multimeters and oscilloscopes to ensure accurate sensor readings.
