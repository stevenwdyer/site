Paradigm Engineering is building an autonomous go-kart to compete in the Autonomous Karting Series National Grand Prix at Purdue University in May 2027.

The go-kart features a NVIDIA Jetson Orin, a Pixhawk 6C, and an STM32G474 microcontroller along with a suite of other devices including a GPS sensor and antenna, RC receiver, Ubiquiti Bullet AC, and several DC motors. As the software lead, I contribute to all aspects of the custom-built software package, which allows for real-time and autonomous control of the go-kart.

Embedded Software (STM32G4)

The STM32G4 runs bare-metal C. Custom drivers were written for CAN communication with the drive motor controller, PWM control for the steering and braking servo motors, and UART communication with the on-board NVIDIA Jetson Orin.

All I/O is interrupt-driven. CAN frames from the drive motor controller arrive through two hardware-filtered receive FIFOs, Jetson commands are parsed byte-at-a-time in the UART ISR, and six RC channels are measured via timer input capture.

Every fault path converges on a single safe state: zero speed commanded, steering centred, brakes applied.

Autonomous Drive Algorithm

The kart's autonomous drive algorithm is run on the Jetson Orin and is built using ROS2. The algorithm is given a .txt file with a list of waypoints and a control node iterates through these waypoints, which computes heading and distance errors relative to the kart's current position. Using this information, it generates steering and velocity commands to guide the kart to the active waypoint. Once reached, the system moves on to the next waypoint.

Computer Vision

The kart's computer vision system utilizes a ZED 2i Stereo Camera that sends a live camera feed to the Jetson Orin which runs a CNN to detect white lines on the race track. This is used alongside the main autonomous drive algorithm for improved waypoint following and correction.

Simulation

The simulation, based on Gazebo, was developed as part of the 2025 software package. It was used for developing and testing the autonomous drive algorithm in the absence of a physical kart.

Deployment

The firmware is flashed onto the STM32G4 via the SWD protocol using an ST-LINK debugger. The Jetson Orin software is deployed using scripted software.
