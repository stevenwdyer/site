This board is used as an interface between an electronic instrument and a host computer for recording music. Effects can also be added and adjusted via firmware.

The goal of this project is to give me a custom, bare-metal platform on which I can try my hand at implementing audio effect algorithms from scratch, as well as record my own music.

Hardware Design

The PCB was designed using KiCAD. The design includes:

  • A 1/4" stereo jack for instrument input. This goes through an op-amp buffer circuit and an inverting amplifier to match the audio codec's 3.3V input requirement.
  • A 1/8" headphone jack, enabling audio streaming to a connected headset.
  • An audio codec to take the analog instrument input and compress it into digital audio to send to the STM32. The codec interfaces with the STM32 via SAI for audio streaming and I2C for control.
  • An STM32H745 microcontroller. It's dual-core is used to split the audio filtering tasks and USB streaming tasks to two different cores, decreasing streaming delay. This interfaces with the audio codec over SAI for audio streaming and I2C for control, a host computer over USB, and multiple indicator LEDs.
  • Two USB connectors, one for power, and one for streaming data to a host computer.
  • A 12.288MHz crystal oscillator as a clock source. This allows for sampling at professional audio rates, such as 48kHz, 96kHz, and 192kHz.
  • An SWD interface, enabling firmware flashing and in-circuit debugging using an external ST-LINK.
  • A 5V to 3.3V ultra-low noise linear regulator, providing clean power to all onboard analog circuitry.
  • A 5V to 3.3V linear regulator, providing power to all onboard digital circuitry.
  • A 3.3V to 1.8V, providing power to the audio codec.
  • User interface, via a reset and user button, as well as power indicator and user indicator LEDs.
